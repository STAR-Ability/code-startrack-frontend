# V0.11 public workspace and practice states

## Goal

Visitors can browse practice without a working session or account list. Personal panels explain login, missing accounts, missing records, and temporary failures clearly.

## Context

The outer session/account providers currently hide the whole workspace. The current user request supersedes the earlier redirect-on-401 UI policy; backend authorization and private query isolation remain mandatory. Reuse installed official shadcn Base UI/Nova components and existing API DTOs.

## Scope

### In Scope

- Always-visible workspace shell and public practice introduction/mode selection.
- Panel-level access gates, private-query isolation, empty states and recoverable failures.
- Responsive Card/Empty/ToggleGroup composition, restrained motion and bilingual text.

### Out of Scope

- Anonymous access to private APIs, invented sample production data, backend changes or dependency migration.

- [x] Relevant regression tests and repository checks pass.

## Decisions / Deviations

- Keep account context strictly authenticated, exposing an optional accessor only for public frame components.
- Use recognized contract error codes to distinguish missing resources from HTML/proxy 404 failures.

- User-level forms keep a stable identity while the account list resolves; only account-scoped panels remount on selected-account changes.
- Regression testing exposed a session-observer notification gap: clearing/recreating the session query did not notify the already mounted shell on a private 401. Keep the session query, set it to null, then remove all other queries and mutation state.
- Missing sync jobs discard their cached progress indicator and release the completed/unknown job UI rather than spinning indefinitely.

- Narrow-screen visual review found cramped mode labels, a tall mobile navigation bar at 200% text size, and auth-header/grid overflow. Mode controls now wrap, mobile navigation scrolls horizontally with the current route brought into view, and auth containers allow wrapping/shrinking.
