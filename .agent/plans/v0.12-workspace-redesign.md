# V0.12 workspace redesign

## Goal

Make collaboration and coaching discoverable, separate team tasks into meaningful deep links, and provide deterministic contract-correct development and verification scenarios.

## Context

Baseline: b68b865 on dev. Root AGENTS.md and .agent/PLANS.md fully reviewed; no nested instruction files found. CodeGraph MCP traced WorkspaceShell, session/account providers, TeamsPage, TeamManagement and query dependencies. Contracts reviewed: both supplied V0.12 documents and every OpenAPI operation/schema. Static export requires fixed pages with UUID query parameters. Preserve same-origin /api/v1, existing auth/client/query layers and additive COACH semantics. No backend, database, Algorithm or provider changes.

Browser audit: detail is about 3751px tall with unrelated member, insight, application, invitation and destructive sections. Navigation is flat; mobile uses a horizontally scrolling list. Search starts blank, team names are not links, coach has only understated text links, privacy/filter controls use native selects. Reports correctly retain frozen snapshots and aggregate pages correctly use /me; preserve these.

Architecture: grouped learning, collaboration, coach (roles includes COACH), accounts/data and settings navigation. Retain collapse cookie/tooltips; mobile Sheet. Team detail route tab controls overview, members, analysis, recommendations, applications, invitations and settings; canManage gates management and canLeave gates leave. Overview contains counts and data readiness with direct links to tasks. Coach links to managed teams and team-scoped queues rather than inventing global owner APIs.

Reusable components: grouped workspace navigation, team header/card, route navigation, team overview, accessible Select field and explicit confirmation dialogs. Reuse Panel, MetricPanel, Status, feedback, query and mutation helpers. Preserve existing tokens, adding restrained orbit headers and grid/surface hierarchy.
