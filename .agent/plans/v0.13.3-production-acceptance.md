## Risks

- Real backend versions differ by family; structural validation remains strong
  and independent of audited-version labels.
- ISO instants permit submillisecond fractions. Independent review found that
  the initial `Date.parse` guard collapsed distinct revisions within one
  millisecond. The shared comparator now preserves full fractional precision
  and equivalent trailing-zero representations without weakening UTC validation.
  Same-millisecond pending-write regressions cover both settings forms.
- Initial concurrent local checks produced a five-second chart-test timeout;
  standalone full and targeted reruns passed. Avoid resource-heavy overlapping
  suites and investigate further only if failure recurs.
- CAPTCHA currently lacks a nonvisual backend alternative. Record this API
  accessibility dependency; do not invent an endpoint or expose challenge answers.
- Preserve WAF and proxy/session security; observation timeouts do not prove
  running work failed or authorize restarting a live process.

## Rollback / Reversibility

Keep the actual previous immutable V0.13.2 image, matching release Compose/env and
restricted backup. Validate and pull the accepted replacement before recreating
only the frontend service. Restore the previous frontend if acceptance fails;
do not alter backend services, databases, volumes or ingress.
