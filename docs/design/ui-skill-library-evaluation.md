### Mandatory project scope when using existing skills

1. **Runner:** shadcn SKILL.md says `pnpm dlx shadcn@latest` throughout, while AGENTS.md requires project-local binaries and avoiding implicit latest downloads. Use `pnpm exec shadcn info --json`, `pnpm exec shadcn docs <name>` and read-only registry view/search via the installed4.21.0 CLI or configured MCP. Do not run latest npx/dlx examples blindly. The task/AGENTS instructions have priority.
2. **Base:** keep `base-nova`, Base UI APIs, Lucide and aliases. Do not apply a global preset/reset or reinstall primitive files as a side effect of styling.
3. **Cards:** skill composition examples such as dashboard=Sidebar+Card+Chart+Table and full-card section guidance are templates, not a mandate to card-wrap everything. Compose each actual Card accessibly, but use open sections, rows and separators when the target hierarchy calls for them.
4. **Typography/colors:** keep styling centralized in semantic tokens and shared variants; task-authorized design-system work may intentionally refine primitive typography/radii/variants. Do not treat the generic skill ban on component typography overrides as forbidding the requested system redesign. Avoid repeated page-local arbitrary values.
5. **Charts/data:** preserve ECharts and TanStack Query, even when a skill suggests Recharts/SWR examples.
6. **No feature additions:** chat primitives, command palette, onboarding, toasts, complex table infrastructure and new controls are considered only when an existing user need requires them. Registry availability does not authorize new product behavior.
7. **CLI mutations:** no preset overwrite or `add --all`. If a selected official component is actually needed in the future redesign, inspect dry-run/diff and code before adapting. The current audit installs nothing.
8. **Browser freshness:** replace the missing browser-skill doc pointer with current `README.md`, `playwright.config.ts`, `playwright.storybook.config.ts`, `scripts/dev-offline.mjs`, `tests/gateway-server.mjs` and fixture/test sources. Evaluate current routes from source; ignore V0.11 release-scope claim.
9. **Synthetic data:** fixture-bound mutation remains mandatory. Build, dev and gateway/E2E processes must not collide over `.next` or owned ports. Interactive MCP isolation is not a network sandbox.
10. **Guideline format:** terse file:line findings are useful input, but final required deliverables need evidence, severity, affected area and direction. The user-specified document format wins over the skill's short report format. Audit already specifies the whole UI scope, so no need to ask which files to review.
