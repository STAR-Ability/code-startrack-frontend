## API 汇总

| 方法     | 路径                                     | 说明             |
| -------- | ---------------------------------------- | ---------------- |
| `POST` | `/api/accounts`                        | 绑定外部平台账号 |
| `POST` | `/api/accounts/{account_id}/sync`      | 同步用户训练数据 |
| `GET`  | `/api/users/{user_id}/profile`         | 获取用户能力画像 |
| `GET`  | `/api/users/{user_id}/recommendations` | 获取推荐题目     |

---

## POST /api/accounts

绑定用户的外部程序设计平台账号。会校验账号在平台上是否存在。

**Request Body**

```json
{
  "user_id": 1,
  "platform": "codeforces",
  "username": "tourist"
}
```

| 字段         | 类型    | 必填 | 说明                                |
| ------------ | ------- | ---- | ----------------------------------- |
| `user_id`  | integer | ✅   | 内部用户 ID                         |
| `platform` | string  | ✅   | 平台标识，V0.1 仅支持`codeforces` |
| `username` | string  | ✅   | 平台用户名                          |

**Response 201**

```json
{
  "account_id": 1,
  "platform": "codeforces",
  "username": "tourist",
  "created_at": "2026-09-29T08:00:00Z"
}
```

**错误响应**

| 状态码  | 场景                  |      |
| ------- | --------------------- | ---- |
| `400` | 平台不支持 / 参数缺失 |      |
| `404` | 平台上找不到该用户名  |      |
| `409` | 该用户已绑定此账号    | 撤销 |
|         | 取消绑定账号          |      |
|         | 用户绑定账号列表      |      |

## POST /api/accounts//sync

同步指定账号的训练数据（提交记录 + 题目信息），写入数据库，自动去重。

**Path Parameter**

| 参数           | 类型    | 说明                     |
| -------------- | ------- | ------------------------ |
| `account_id` | integer | external_accounts 表主键 |

**Request Body**：无

**执行流程**

```
读取绑定账号
↓
调用 CodeforcesProvider.get_submissions()
↓
获取对应题目信息（CodeforcesProvider.get_problems()）
↓
标准化数据
↓
去重写入（基于 external_submission_id 唯一约束）
↓
更新 external_accounts.last_synced_at
```

**Response 200**

```json
{
  "status": "success",
  "new_submissions": 35,
  "total_submissions": 428,
  "synced_at": "2026-09-29T08:05:00Z"
}
```

**错误响应**

| 状态码  | 场景                  |
| ------- | --------------------- |
| `404` | account_id 不存在     |
| `502` | 外部平台 API 请求失败 |

## GET /api/users//profile

获取用户当前能力画像，供前端画像页使用。

**Path Parameter**

| 参数        | 类型    | 说明         |
| ----------- | ------- | ------------ |
| `user_id` | integer | users 表主键 |

**Response 200**

```json
{
  "userId": 1,
  "totalSolved": 123,
  "averageDifficulty": 1200,
  "maxDifficulty": 1700,
  "skills": [
    { "name": "dp", "score": 0.42 },
    { "name": "graph", "score": 0.35 },
    { "name": "greedy", "score": 0.71 },
    { "name": "math", "score": 0.63 }
  ],
  "recentActivity": {
    "last_7_days": 12,
    "last_30_days": 45
  },
  "updatedAt": "2026-09-29T08:10:00Z"
}
```

| 字段                  | 类型    | 说明                        |
| --------------------- | ------- | --------------------------- |
| `totalSolved`       | integer | AC 题目总数                 |
| `averageDifficulty` | float   | 已解题平均 Rating           |
| `maxDifficulty`     | integer | 已解题最高 Rating           |
| `skills`            | array   | 各知识点能力分（0.0 ~ 1.0） |
| `recentActivity`    | object  | 近期提交数统计              |

**错误响应**

| 状态码  | 场景                      |
| ------- | ------------------------- |
| `404` | 用户不存在 / 尚未生成画像 |

## GET /api/users//recommendations

获取为用户生成的推荐题目列表。

**Path Parameter**

| 参数        | 类型    | 说明         |
| ----------- | ------- | ------------ |
| `user_id` | integer | users 表主键 |

**Query Parameter**

| 参数      | 类型    | 默认值 | 说明                      |
| --------- | ------- | ------ | ------------------------- |
| `limit` | integer | 10     | 返回题目数量上限，最大 50 |

**示例请求**

```
GET /api/users/1/recommendations?limit=10
```

**Response 200**

```json
{
  "userId": 1,
  "recommendations": [
    {
      "problemId": 101,
      "platform": "codeforces",
      "externalProblemId": "1234B",
      "title": "Example Problem",
      "difficulty": 1300,
      "tags": ["dp", "greedy"],
      "url": "https://codeforces.com/problemset/problem/1234/B",
      "score": 0.84,
      "reason": "当前 DP 是你的相对薄弱知识点，该题难度略高于当前稳定水平。"
    }
  ],
  "generatedAt": "2026-09-29T08:10:00Z"
}
```

| 字段                  | 类型    | 说明                       |
| --------------------- | ------- | -------------------------- |
| `problemId`         | integer | 内部 problem ID            |
| `externalProblemId` | string  | 平台题目 ID（如`1234B`） |
| `difficulty`        | integer | 题目 Rating                |
| `score`             | float   | 推荐分数（0.0 ~ 1.0）      |
| `reason`            | string  | 推荐原因（中文自然语言）   |

**错误响应**

| 状态码  | 场景                      |
| ------- | ------------------------- |
| `404` | 用户不存在 / 尚未生成推荐 |

---

## 通用错误格式

所有错误响应统一格式：

```json
{
  "error": "account_not_found",
  "message": "Account with id 99 not found."
}
```

---

## 开发顺序建议

1. `POST /api/accounts` — 先跑通账号绑定
2. `POST /api/accounts/{id}/sync` — 数据同步是核心
3. `GET /api/users/{id}/profile` — 画像依赖同步数据
4. `GET /api/users/{id}/recommendations` — 推荐依赖画像
